# Вход в профиль

Сайт открыт для всех. Админка доступна только двум email:

- `vsasa9064@gmail.com`
- `gurdalievaekaterina1010@gmail.com`

Запуск из папки проекта:

```bash
python3 server.py
```

По умолчанию пароль: `atelier`. Свой пароль можно задать так:

```bash
ADMIN_PASSWORD='ваш-пароль' python3 server.py
```

Откройте `http://localhost:8000`, справа сверху `↗` → «Войти в профиль». После входа можно менять карточки, добавлять и удалять работы, загружать фото. Фото сохраняются в `photos`, данные — в `content/gallery.json`.
